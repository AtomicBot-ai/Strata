# Atomic Turbine v0.1 alpha

Локальный релиз для macOS arm64 / Metal на базе Strata 0.1.69 (b28ca95e). Проверенные конфигурации — Inkling-2-Mini SQ-10 / FP16 KV и Qwen3.8-Flash-Next IQ3_XXS с общей ареной экспертов 6 GB. Оба профиля используют два активных слота, выключенный drafter и один родительский checkpoint на процесс. У Qwen зарезервирован третий физический слот до завершения процесса.

Главное изменение — явное управление общим текстовым контекстом через HTTP. Обычный chat/completions использует штатный путь. После создания checkpoint клиент отправляет совместимые продолжения, а сервер проверяет общий токенный префикс до начала стрима. Подготовка родителя требует prefill и памяти.

В ZIP включён воспроизводимый Python-клиент. OpenCode подключается обычным OpenAI-compatible provider; прозрачное наследование состояния для субагентов остаётся DEFER. Для интерактивного чата и для качества ответов преимущество не заявляется.

Установка и ограничения описаны в README.md. Веса, Python-окружение и OpenCode устанавливаются отдельно. Архив локальный, без Developer ID и notarization.
