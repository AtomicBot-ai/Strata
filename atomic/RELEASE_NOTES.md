# Atomic Turbine v0.1 alpha

Локальный релиз для macOS arm64 / Metal на базе Strata 0.1.69 (b28ca95e). Проверенные конфигурации — Inkling-2-Mini SQ-10 / FP16 KV и Qwen3.8-Flash-Next IQ3_XXS с общей ареной экспертов 6 GB. Оба профиля используют два активных слота, выключенный drafter и один родительский checkpoint на процесс. У Qwen зарезервирован третий физический слот до завершения процесса.

Главное изменение — явное управление общим текстовым контекстом через HTTP. Обычный chat/completions использует штатный путь. После создания checkpoint клиент отправляет совместимые продолжения, а сервер проверяет общий токенный префикс до начала стрима. Подготовка родителя требует prefill и памяти.

В ZIP включён воспроизводимый Python-клиент. OpenCode подключается обычным OpenAI-compatible provider; в проверке OpenCode 2.0.24 успешно делегировал чтение файла и вернул 8080. У build и explore различались первые сообщения. Прозрачное наследование состояния для субагентов остаётся DEFER. Для интерактивного чата и для качества ответов преимущество не заявляется.

Установка и ограничения описаны в README.md. Веса, Python-окружение и OpenCode устанавливаются отдельно. Архив локальный, без Developer ID и notarization.

## Замеры релиз-кандидата

Apple M4 Max, 48 ГиБ, три парных повтора против Strata `b28ca95e`, одинаковые веса, включённые штатные cache и batching. Медианы:

| Сценарий | Strata | Atomic Turbine | Результат |
|---|---:|---:|---|
| Четыре вопроса по исходнику launcher через HTTP, Inkling SQ-10 | 10,14 с | 3,89 с | 12/12 точных ответов в каждом режиме, 12 подтверждённых восстановлений суммарно. Время включает создание родителя и удаление. |
| Qwen IQ3_XXS, четыре нативные ветки, общий префикс 22 токена | 14,66 с | 9,45 с | Токены совпали во всех трёх парах. Первый fork-прогон занял 20,76 с против 14,64 с у Strata. |
| Тот же Qwen, четыре вопроса к инструкции в 121 токен | 17,88 с | 14,42 с | Токены совпали во всех трёх парах. |

В синтетическом Inkling fan-out 16K/4 и 32K/8 после одинакового начального prefill времена составили 41,88 → 5,50 с и 80,50 → 15,03 с. Свободная генерация при разном расписании дала разные токенные последовательности, а в части веток — разное число выходных токенов. Эти цифры показывают время конкретных прогонов. Проверка корректности с одинаковой формой вычисления приведена отдельно в RELEASE_STATUS.md исходного репозитория.

Во всех измерениях доступны только два одновременных слота. Медианы пика памяти на HTTP-сценарии — 4,12 GiB в Strata и 4,31 GiB в Turbine. Время OpenCode и дисковый ввод-вывод в приведённые сравнения не входят.
