# Atomic Turbine · финальный спринт

Apple M4 Max, 48 ГиБ объединённой памяти, Metal. База — Strata 0.1.69 (`b28ca95e`). Для S01–S03 взяты три парных повтора с перестановкой порядка режимов. Ниже приведены медианы времени и медианы ускорений внутри пар. В S04 оценивается выполнение трёх разных задач.

**S01 · INTEGRATE.** Inkling-2-Mini SQ-10, FP16 KV. Время начинается после обработки общего родителя и заканчивается после очистки. Из двух штатных вариантов подачи быстрее оказалась последовательная подача. На **16K / 4 ветки** штатный режим занял **10,17 с**, fork — **7,29 с** (1,39×). На **32K / 8 веток** — **22,93 и 16,12 с** (1,42×). После завершения первых двух веток время на одну оставшуюся снизилось с 2,54 до 1,80 с и с 2,86 до 1,99 с соответственно (−29,2% и −30,4%). Создание снимка заняло 61 и 108 мс, все восстановления в дереве — 83 и 233 мс. Пиковая память выросла с 3,47 до 4,13 и с 4,47 до 5,63 ГиБ. При одинаковом расписании все 12 конечных векторов FP32 побайтово совпали с пересчётом. Нагрузка синтетическая, с 128 заданными шагами продолжения. Во время части первого блока 16K на CPU шла сборка.

**S02 · INTEGRATE.** Qwen3.8-Flash-Next IQ3_XXS, два активных слота, три выделенных, общая Metal-арена экспертов 6,00 ГБ. Один и тот же 22-токенный префикс, по 16 выходных токенов на ветку. В измерение входит начальная обработка префикса.

| Ветки | A · последовательно | B · fork | C · штатный batching | D · fork + batching | Ускорение D к C | Чтение SSD, C → D |
|---|---:|---:|---:|---:|---:|---:|
| 2 | 9,12 с | 7,06 с | 7,72 с | 5,88 с | **1,31×** | 21,40 → 17,12 ГБ |
| 4 | 16,52 с | 11,04 с | 14,61 с | 9,39 с | **1,56×** | 38,30 → 26,39 ГБ |

Пик C и D — около 14,7 ГиБ. Все токены четырёх режимов совпали. В отдельной проверке 16 операций сохранения и восстановления зарезервированной строки дали точную копию проверяемых буферов. Физическое чтение взято со всего устройства disk0. Логический счётчик охватывает только наблюдаемые обращения к экспертам при декодировании. Для четырёх веток он даже вырос с 13,20 до 13,86 ГБ при падении физического чтения на 31%. Результат относится к коротким запросам и доступному файловому кешу.

**S03 · DROP.** Восемь запросов из двух семейств, два активных слота. Все доступны одновременно. Сравнивались порядки подачи в штатный движок. FIFO / случайная перестановка / группировка заняли **32,03 / 33,08 / 31,34 с**, дали **4,00 / 3,87 / 4,08 выходных токена/с** и **84,24 / 88,19 / 81,58 ГБ** чтения с disk0. Доли попаданий в кеш на наблюдаемых шагах — 68,6 / 64,7 / 70,2%. При одинаковых токенах и объёме работы группировка выиграла 2,2% по скорости и 3,0% по чтениям в парном сравнении. Целевые пороги — 10% и 15%. Хотя p95 задержки снизился на 2,2%, один запрос при группировке завершался в 2,72 раза позже. Сохранён штатный порядок подачи.

**S04 · INTEGRATE для API, DEFER для прозрачного fork.** OpenCode 2.0.24 через локальный OpenAI-совместимый API, Inkling и два слота. Базовый путь — обычные запросы OpenCode к Strata. Обзор реального кода занял 65 с: клиент нашёл функции установки и выбора feed, но в итоговом пути пропустил подкаталог `shapes`. За 93 с клиент исправил исторический баг #7119 в отдельной копии репозитория. Проверка подтвердила передачу причины в GUI, сохранение вывода в терминале и режима пропуска установки. Два explore-субагента завершили третью задачу за 164 с, их сессии перекрывались на **128 с**. На проводе наблюдались два активных слота, 28 событий возобновления префикса и **0 сохранений / 0 восстановлений native fork**. Пик процесса движка — 4,22 ГиБ. Понадобится адаптер с явной связью родителя и ветки. Три задачи дают проверку совместимости на одном клиенте и модели. Исходная неуспешная попытка с неверно названной обёрткой сохранена отдельно.

**Сборка v0.1.0.** Локальная ветка `atomic-turbine/v0.1`, коммит `30aa2bf0`. Сохранены 8 807 предшествующих коммитов Strata. В архив входят два движка Metal, HTTP-сервер, инструкции и лицензии. Снимки включаются явно. У Inkling задаётся лимит полезной нагрузки, у Qwen резервируется третий физический слот, а два доступны запросам. На распакованных бинарниках проверены отмена, устаревшие идентификаторы, изоляция слотов, сохранение выходных токенов и жизненный цикл снимка. Удержанный объём памяти между контрольными точками составил 0 байт на 110 циклах Inkling и 26 циклах Qwen. На диагностическом Inkling полные FP32-векторы совпали также при восстановлении в соседний слот и при новом запросе после отмены. Бюджет 32 МиБ отклонил префикс из 191 токена и принял 63 токена (16 220 412 байт). Проверены хеши 677 файлов распакованного ZIP. API ответил `hello` с причиной завершения `stop`; при лимите в 8 токенов успело пройти только рассуждение. Полный набор тестов, длительный нагрузочный прогон и конкурентные бенчмарки не запускались.
