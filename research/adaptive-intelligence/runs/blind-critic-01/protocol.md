# Слепой выбор действия в Strata

Основной показатель — доля финальных правильных ответов при лимите 2 048 обработанных моделью токенов после общего черновика. Включаются все десять задач, по три парных seed продолжения. Критик принимает одно решение на задачу до генерации любой ветки. Контроль игнорирует черновик и начинает с исходного условия. Критик видит условие, черновик, сигнал об остановке и, для кода, результаты публичных примеров. Образцы из условия разрешены обеим сторонам. Эталоны и закрытые тесты используются только для окончательной оценки.

Критик и генератор используют одни веса. Решение критика задаёт только действие, его объяснение генератору не передаётся. Сохранённый префикс воспроизводится из токенов. Чтение промпта, генерация критика и повторное чтение префикса входят в лимит. Время CPU на публичные примеры сохраняется отдельно. При исчерпании лимита перед продолжением остаётся исходный черновик. Некорректная метка означает новый старт с оплатой критика.

Дополнительный срез даёт каждой генерируемой ветке до 448 новых токенов. Сравнения — выбранное действие против нового старта, против правила «продолжить оборванное, оставить завершённое» и против лучшего доступного действия, выбранного после проверки. Последнее служит только оценкой упущенных возможностей. Отдельно считаются направления расхождений, включая случаи, когда исходный черновик был верен.

Единица независимого наблюдения — задача. Для оценки неопределённости разности долей используем описательный 95%-й процентильный интервал бутстрэпа по десяти задачам, сохраняя три seed вместе. Положительным сигналом для расширения опыта считаем прирост от 5 процентных пунктов с нижней границей выше нуля. По математике и коду показываем числители и знаменатели. Вывод относится к этой политике и этой выборке.
