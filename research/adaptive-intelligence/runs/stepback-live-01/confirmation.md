# Резерв для подтверждения

Правило фиксируется до открытия скрытых оценок пилота. Если основной критерий выполнен, выбрать для независимого подтверждения первые восемь easy, восемь medium и восемь hard из оставшихся задач AtCoder на той же закреплённой ревизии. Исключить целиком соревнования, из которых брались задачи для этого пилота, калибровки и прежних исследований. Сортировка внутри уровня — по SHA-256 строки stepback-confirm-v1/ и ID задачи. Нужны минимум четыре разных соревнования и непустые публичные и закрытые stdin-примеры. Отсутствующие файлы не считать отсутствующими задачами: выбор фиксируется по полному списку допустимых ID до генерации.

Сравнение D с зафиксированным контролем проводится с тем же дедлайном 30 секунд, моделью, селектором, пределом памяти и правилом решения. На подтверждении seed 4303, 4357 и 4391. При выигрыше только фиксированного дерева C его проверка образует отдельную гипотезу, которая требует собственного зафиксированного сравнения.
