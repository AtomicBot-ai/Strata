Step 1: For each instruction, fix the unspecified hand's position (it cannot be moved), and compute the shortest number of steps for the specified hand to go from its current position to T_i along the ring. Two hand positions must stay distinct, so for a hand moving along the ring, the destination must not equal the fixed hand. The shortest path along the ring while avoiding the fixed hand is the shorter arc that does not pass through the fixed position; equivalently, if the fixed hand is blocking one side of the ring, the moving hand must go the other way.

Step 2: For each instruction i, enumerate all possible positions for the specified hand (including the destination T_i) and choose the one minimizing the distance to T_i, subject to the fixed hand not being at the destination and not equal to the moving hand throughout. Since the moving hand moves one step at a time, we only need to consider the two arcs between its current position and T_i; if one arc is blocked by the fixed hand, we must use the other arc. Tracking the best possible position of the specified hand after the instruction gives a small dynamic state.

Step 3: Process all Q instructions sequentially. Maintain a map from the current position of the specified/other hands that are not fixed? In fact, for each instruction, only one hand moves and the other is fixed, so after the instruction we record the resulting position of the moving hand and the fixed hand unchanged. For each possible moving-hand destination state, compute the operation count. Since Q ≤ 100 and N ≤ 100, we can use a simple shortest-path search over ring positions for each instruction while enforcing that the moving hand cannot step onto the fixed hand.

```python
import sys

def solve():
    data = sys.stdin.read().split()
    idx = 0
    N = int(data[idx]); idx += 1
    Q = int(data[idx]); idx += 1
    instructions = []
    for _ in range(Q):
        H = data[idx]; T = int(data[idx+1]); idx += 2
        instructions.append((H, T))

    l = 1
    r = 2
    total = 0

    def ring_dist(start, target, forbidden):
        # positions numbered 1..N, adjacency cyclic
        # cannot pass through forbidden (the fixed hand). moving hand must not enter forbidden.
        # Compute minimal steps from start to target avoiding forbidden.
        # Since start != target and target != forbidden.
        # Two directed paths on cycle: clockwise and counterclockwise.
        def steps_to(direction):
            # direction +1 means increasing part with wrap (1->2->...->N->1), direction -1 means decreasing
            pos = start
            cnt = 0
            while pos != target:
                if direction == 1:
                    pos = pos + 1
                    if pos > N:
                        pos = 1
                else:
                    pos = pos - 1
                    if pos < 1:
                        pos = N
                cnt += 1
                if pos == forbidden:
                    return None
                if cnt > N:
                    return None
            return cnt
        cw = steps_to(1)
        ccw = steps_to(-1)
        vals = [v for v in (cw, ccw) if v is not None]
        if not vals:
            # Cannot pass forbidden? But guaranteed achievable. Return None
            return None
        return min(vals)

    for H, T in instructions:
        if H == 'L':
            fixed = r
            start = l
            # target T must != fixed (guaranteed)
            d = ring_dist(start, T, fixed)
            # Moving hand should not equal fixed along path; distance ensures avoidance.
            # But is the path length always equal to minimal operations? Need ensure the path does not enter fixed hand and also cannot pass through? yes.
            if d is None:
                raise ValueError("Not achievable")
            total += d
            l = T
        else:
            fixed = l
            start = r
            d = ring_dist(start, T, fixed)
            if d is None:
                raise ValueError("Not achievable")
            total += d
            r = T

    print(total)

solve()
