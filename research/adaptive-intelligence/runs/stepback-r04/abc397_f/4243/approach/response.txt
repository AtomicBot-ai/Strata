Step 1:
For each split position, the distinct count in the first subarray is prefix_distinct[i]. For the middle segment, we can precompute prefix distinct counts and then compute distinct in (i+1..j) as prefix_distinct[j] - (number of distinct values in prefix i that also appear in segment) — but simpler: for each j, track the distinct values in the segment (i+1..j) by re-evaluating as we scan i.

Step 2:
Iterate over j from 2 to N-1. Maintain a frequency map of values in the suffix segment (j+1..N). For each i from 1 to j-1, compute left distinct count as prefix_distinct[i], middle distinct count as distinct values in (i+1..j) — obtained by maintaining counts as i changes, and right distinct count as number of distinct values in suffix. Use a sliding data structure: as i increases, remove A_i from the middle segment.

Step 3:
We can use an O(N^2) approach with optimized maps if N is up to 3e5, but better to use known efficient approach: iterate i and maintain distinct counts for prefix, middle, suffix using dictionary tracking.
