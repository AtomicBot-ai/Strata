Step 1: For each position k, compute left[k] = number of distinct values in A[1..k], and right[k] = number of distinct values in A[k+1..N].

Step 2: For a split (i,j), the total is left[i] + (distinct in A[i+1..j]) + right[j]. Need efficient way to handle the middle segment.

Step 3: Since N <= 3e5, use segment-tree-like or precomputed prefix/suffix with a two-pointer/dictionary? Simpler robust approach: iterate i from 1 to N-2, maintain a dictionary of counts for the middle segment as j increases; track distinct count. Then answer = left[i] + distinct + right[j], maximize over j>i and j <= N-1.

Final:
```python
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))

    left = [0] * (n + 1)
    seen = set()
    for idx in range(1, n + 1):
        seen.add(a[idx - 1])
        left[idx] = len(seen)

    right = [0] * (n + 1)
    seen = set()
    for idx in range(n, 0, -1):
        seen.add(a[idx - 1])
        right[idx] = len(seen)

    ans = 0
    for i in range(1, n - 1):
        counts = {}
        distinct = 0
        for j in range(i + 1, n):
            x = a[j - 1]
            if x not in counts:
                distinct += 1
            counts[x] = counts.get(x, 0) + 1
            # middle segment is i+1..j (1-indexed), right[j] is suffix after j
            total = left[i] + distinct + right[j]
            if total > ans:
                ans = total
    print(ans)

main()
