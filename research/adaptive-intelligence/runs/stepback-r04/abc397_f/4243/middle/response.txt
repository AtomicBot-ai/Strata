Step 1: For each position k, compute left[k] = number of distinct values in A[1..k], and right[k] = number of distinct values in A[k+1..N].

Step 2: The total for split at (i,j) is left[i] + distinct(i+1..j) + right[j]. For fixed i, the middle count depends on the set of values seen since i+1. Sweep j while maintaining the current distinct count (using a frequency map), and track the maximum of left[i] + cur + right[j].

Step 3: Iterate i from 1 to N-2, reset the middle map for each i, advance j from i+1 to N-1, and keep the best value. Output the best total.

Final:
```python
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))
    left = [0] * (n + 1)
    seen = set()
    for k in range(1, n + 1):
        seen.add(a[k - 1])
        left[k] = len(seen)
    right = [0] * (n + 1)
    seen = set()
    for k in range(n, 0, -1):
        seen.add(a[k - 1])
        right[k - 1] = len(seen)
    best = 0
    for i in range(1, n - 1):
        cur = 0
        freq = {}
        for j in range(i + 1, n):
            v = a[j - 1]
            if freq.get(v, 0) == 0:
                cur += 1
            freq[v] = freq.get(v, 0) + 1
            total = left[i] + cur + right[j]
            if total > best:
                best = total
    print(best)

if __name__ == "__main__":
    main()
