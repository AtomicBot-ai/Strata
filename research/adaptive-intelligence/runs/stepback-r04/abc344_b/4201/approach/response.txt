Step 2: Reverse the list of integers.
Step 3: Print each reversed integer on its own line.

Final:
```python
import sys

lines = sys.stdin.read().splitlines()
values = [int(line.strip()) for line in lines if line.strip()]
for value in reversed(values):
    print(value)
