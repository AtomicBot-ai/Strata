Step 1: Read all lines from stdin.
Step 2: The input terminates at the first line with 0; treat that as A_N and all previous lines as A_1..A_{N-1}.
Step 3: Print those values in reverse order, with the final 0 first.

Final:
```python
import sys

lines = sys.stdin.read().splitlines()
values = []
for line in lines:
    if line.strip() == '':
        continue
    v = int(line.strip())
    if v == 0:
        values.append(0)
        break
    values.append(v)

out = values[::-1]
print('\n'.join(map(str, out)))
