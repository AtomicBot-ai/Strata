Step 1: Read all integers from standard input; since N is not given, parse the stream until EOF.
Step 2: Reverse the list of integers.
Step 3: Print the reversed integers one per line.

Final:
```python
import sys

def main():
    lines = sys.stdin.read().splitlines()
    vals = []
    for line in lines:
        line = line.strip()
        if line:
            vals.append(int(line))
    for v in reversed(vals):
        print(v)

if __name__ == "__main__":
    main()
