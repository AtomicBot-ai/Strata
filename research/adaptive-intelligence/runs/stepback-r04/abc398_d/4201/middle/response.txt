Step 1: Track smoke using a set of (r,c) cells. At each t, move every existing cell by the direction of S[t-1], then generate new smoke at (0,0) if no smoke is at (0,0) after the move.

Step 2: For each t from 1..N, query the set for (R,C) and append '1' or '0' to the output.

Step 3: The process can grow large, but the target (R,C) only needs the set of positions; each step moves all cells. Keeping only cells that can reach (R,C) is hard, so instead maintain all cells but note generation happens only when origin is empty. For this problem structure, keep all cells and use a simple set; N up to 200000 and directions keep cells within a bounded region.

```python
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0])
    R = int(data[1])
    C = int(data[2])
    S = data[3]
    smoke = {(0, 0)}
    ans = []
    for i in range(N):
        d = S[i]
        new = set()
        for r, c in smoke:
            if d == 'N':
                new.add((r - 1, c))
            elif d == 'W':
                new.add((r, c - 1))
            elif d == 'S':
                new.add((r + 1, c))
            else:
                new.add((r, c + 1))
        if (0, 0) not in new:
            new.add((0, 0))
        smoke = new
        ans.append('1' if (R, C) in smoke else '0')
    print(''.join(ans))

if __name__ == '__main__':
    main()
