Step 1: Read the 64 bits from stdin as a list of integers.
Step 2: For each bit position i with value A_i, add A_i * 2^i to the total.
Step 3: Print the total integer.

Final:
```python
import sys

def main():
    data = sys.stdin.read().split()
    bits = list(map(int, data[:64]))
    value = 0
    for i, b in enumerate(bits):
        if b:
            value += 1 << i
    print(value)

if __name__ == "__main__":
    main()
