# E00 · Strata на Apple Silicon

25 ноября 2026. Базовая конфигурация исследования — Strata Inkling 0.1.65, Metal, Inkling-2-Mini SQ-10. На одном коротком запросе два независимых процесса выдали одинаковую последовательность из 16 токенов и остановились по лимиту. Шаг допускает эксперименты с независимыми запросами на Metal. Для проверки экономии физических чтений SSD нужен другой режим Strata с наблюдаемым вытеснением экспертов.

## Исходники и артефакты

- Отдельная локальная копия upstream в `Strata/`, ветка `research/adaptive-intelligence`. В рабочей копии выбраны каталоги, необходимые для Inkling. Зафиксирован SHA `26350e4387b8019b0f6825ba78b87eb6360159e7` из BUILD.json готового Metal-компонента. На момент проверки публичный тег v0.2.19 раскрывался в `c6f6427d9de9016fd92d13e29740f65625261df7`. Для повторения нужен SHA. Корневая лицензия MIT. [Исходная ревизия](https://github.com/Niko1221/Strata/tree/26350e4387b8019b0f6825ba78b87eb6360159e7) · [Лицензия](https://github.com/Niko1221/Strata/blob/26350e4387b8019b0f6825ba78b87eb6360159e7/LICENSE)
- Apple M4 Max, 16 ядер CPU, 40 GPU, 48 GiB объединённой памяти, macOS 27.2.1 (26B131). Образ модели занимает 10 471 526 400 байт. Релизный бинарник и модель проверены по SHA-256. Пути, хеши, токенизатор, запрос и команда запуска сохранены в каждой строке [данных](runs/strata-e00/baseline.jsonl). Готовые файлы использованы из локального кэша. Их расположение можно изменить параметрами скрипта.
- Вход — 12 токенов фразы «The first ten positive integers are 1, 2,». Без шаблона чата, greedy, draft выключен, один слот, KV FP16, контекст 512. Запись STDIN/STDOUT позволяет проверить количество токенов и причину остановки. Выход в обоих случаях — ` 3, 4, 5, 6, 7, `. Это проба механики генерации. Внешние датасеты и оценка качества для неё не требуются.

Проверка хеша читает файл модели перед серией. Между процессами состояние файлового кэша не контролировалось. Поэтому цифры старта нельзя трактовать как cold/warm сравнение. Два повтора проверяют воспроизводимость токенов на этом входе. Распределение задержек, качество и расход энергии остаются неизмеренными. У процессного счётчика нет разбивки по файлу, слою или эксперту. Объём физических чтений SSD по экспертам оставлен неопределённым.

| Возможность | Что установлено в этой ревизии |

| Размещение весов | Inkling Metal отображает весь файл модели через mmap и оборачивает диапазон в один или несколько Metal-буферов. STATS присваивает числу загруженных экспертов их общее количество. Значение 3072/3072 подтверждено запуском. Управляемый лимит на резидентные эксперты, фактические промахи и физические байты по экспертам на этом пути не установлены. [Загрузчик, строка 426](../../Strata/engine/src/inkling2/metal/ink_metal_common.h#L426) · [STATS, строка 74](../../Strata/engine/src/inkling2/metal/ink_metal_backend.mm#L74) |

## Команды воспроизведения

Из корня рабочей папки, с CMake, Apple Clang, macOS SDK и Python с tokenizers 0.22.2. Сборка выбирает только исполняемый файл Inkling и необходимые библиотеки. Измерения выполнялись готовым Metal-компонентом с проверенным хешем.

```sh
git -C Strata rev-parse HEAD
cmake -S Strata/engine/src/inkling2 -B .work/strata-build -DCMAKE_BUILD_TYPE=Release
cmake --build .work/strata-build --target strata-inkling --parallel 2
python3 -B research/adaptive-intelligence/baseline.py research/adaptive-intelligence/runs/strata-e00-repeat
```

Каталог результатов при каждом запуске должен быть новым. [Протокол](protocol.yaml) · [Скрипт](baseline.py) · [Сырой обмен первого запуска](runs/strata-e00/strata-1.protocol) · [Второго](runs/strata-e00/strata-2.protocol)

## Следующий эксперимент

Для E02 пригоден собственный `--bench` Strata. Он строит отдельный синтетический prompt для каждого слота. Пара ниже измерит совокупную скорость обычного batching. Чтобы оценить цену ветки, потребуется добавить контроль с теми же двумя последовательностями, выполненными по очереди, и отдельно проверить форк общего префикса. Время загрузки, prefill и decode следует учитывать раздельно. [Формирование входов, строка 152](../../Strata/engine/src/inkling2/ink_main.cpp#L152)

```sh
component=../atomic-turbine/.work/inkling-strata/engine/strata-inkling
weights=../atomic-turbine/.work/models/Inkling-2-Mini-SQ-10.strata
for slots in 1 2
do
  "$component" --bench --native "$weights" --parallel "$slots" --draft off --kv fp16 --max-context 512 --chunk 128 --prompt-len 32 --gen 16
done
```

По E01 пока можно измерять пересечение маршрутов top-8. Для решений по SSD-планировщику необходимо подтвердить на выбранной реализации Strata ограничиваемый кэш экспертов и связать его промахи с дисковым вводом. Решение по этой гипотезе остаётся открытым.
