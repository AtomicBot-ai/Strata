# StepBack на двух слотах Metal

Пилот использует одну загруженную Inkling-2-Mini SQ-10, FP16 KV, контекст 4096, два слота и выключенный draft. На запрос отводится 30 секунд, включая токенизацию, поиск и проверку публичных примеров. Таймер доставки резервирует последние 20 мс на публикацию. После публикации драйвер отменяет оставшиеся ветки и дожидается очистки и завершения изолированных проверок до следующего запроса.

## Режимы и выбор ответа

A выполняет одну попытку, B запускает до четырёх независимых попыток по мере освобождения двух слотов. C запускает два корня и по одному дополнительному продолжению для каждого. Граница — первый начинающийся на новой строке маркер Final: или открытие блока Python. Движок сохраняет распределение, из которого вышел первый токен маркера, и состояние после обработки предшествующего токена. После подтверждения всего маркера ребёнок получает отдельный seed и заново сэмплирует с этой границы. Если до завершения корня не появилось маркера, дополнительная попытка начинается с условия. D обслуживает ту же очередь. Когда в ней есть работа и активные родитель и ребёнок совпадают по всему наблюдаемому общему суффиксу длиной от 32 токенов, D отменяет младшую ветку. Политика проверяет одну форму отсечения дублирующихся траекторий.

Кандидат поступает на проверку по штатному завершению или лимиту контекста. Извлечение Python и изолированный Docker-оценщик общие для всех режимов. Проверенный кандидат с наибольшим числом пройденных публичных примеров получает приоритет. При равенстве выбирается раньше проверенный. Когда кандидат проходит все примеры, ответ можно выдать немедленно. Повтор той же программы в запросе проверяется один раз. Запись в deliveries.jsonl публикуется до ожидания очистки. По скрытым тестам оценивается только зафиксированное решение и, отдельно, достижимое покрытие среди уже готовых кандидатов.

## Воспроизведение

Нужны условия из reproduce.md, доступ к Metal и закреплённый образ Docker, Python с tokenizers и numpy. Все команды выполняются из корня turbine-intelligence. Для нового опыта имена каталогов должны быть свободны. Сохранённые tasks.json, protocol.json и хеши источников фиксируют конкретную выборку. Новый отбор исключает задачи из предыдущих прогонов.

```sh
cmake --build .work/strata-build --target strata-inkling --parallel 2
lab=research/adaptive-intelligence/branching
out=research/adaptive-intelligence/runs/stepback-live-01
python3 -B "$lab/live_gate.py" research/adaptive-intelligence/runs/live-fork-gate-01
python3 -B "$lab/stepback_data.py" fetch
python3 -B "$lab/stepback_data.py" prepare "$out"
python3 -B "$lab/live_trial.py" calibrate "$out"
python3 -B "$lab/live_trial.py" pilot "$out"
python3 -B "$lab/live_trial.py" grade "$out"
```

Калибровка определяет основной контроль по числу решённых задач на старых ID, затем по медиане задержки. lock.json сохраняет все 288 назначений, версии кода, весов, данных и бинарника. Возобновление pilot пропускает только полностью записанные задания. grade проверяет наличие всех заданий до обращения к скрытым ответам пилота. Публикуются исходы по задачам и seed, выбранная точность, достижимое покрытие, задержки, память и активность политики. Описательный парный bootstrap пересэмплирует целые задачи с тремя seed. Заранее заданный сигнал для подтверждения на новой выборке — преимущество D над выбранным контролем от 5 п.п. при нижней границе интервала выше нуля.
