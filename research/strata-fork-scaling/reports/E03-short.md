# E03. Сравнение скорости после E02-R

Полная серия E03 на паузе. Для общего префикса 16 384 и восьми веток выполнена одна дополнительная пара. E02-R до начала этих измерений прошёл независимую проверку. Все значения ниже относятся к Inkling SQ-10 на одном M4 Max, при двух выделенных слотах и 128 заданных шагах на ветку. Обе системы обрабатывали те же ID. Во всех включённых парах совпали и конечные выбранные токены.

## Одно длинное дерево

Одинаковый лимит двух рабочих слотов позволяет штатному движку обрабатывать ветки по очереди, если это быстрее. Перед сравнением на отдельном дереве измерены оба штатных расписания. Для восьми веток они заняли 45,29 с при ширине один и 104,89 с при ширине два. В качестве основного контроля выбрана ширина 1.

- 2 веток — штатный режим 30,20 с, снимок 28,84 с, ускорение 1,05×. Пиковый физический размер процесса 3,52 и 4,02 ГиБ соответственно.
- 8 веток — штатный режим 45,11 с, снимок 39,43 с, ускорение 1,14×. Пиковый физический размер процесса 3,52 и 4,02 ГиБ соответственно.

Для каждого из двух длинных случаев есть одна измерительная пара. По ним нельзя оценить устойчивость ускорения или доверительный интервал.

Максимум из полностью измеренных случаев с ветвлением — 1,276× при общем префиксе 1024 и 4 ветках. Для перехода к независимому подтверждению протокол требует 1,30× в скрининге. Для оставшихся размеров результат открыт. Формального решения G1 по всей матрице нет.

Физический размер процесса взят из Darwin proc_pid_rusage. Веса отображены в память, аллокации Metal учитываются отдельно. Жёсткого лимита памяти в этом опыте не задавали. Данные не дают оценки числа агентов, помещающихся в память.
