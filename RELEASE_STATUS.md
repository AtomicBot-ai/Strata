# Atomic Turbine v0.1 alpha

| Этап | Статус | Свидетельство |
|---|---|---|
| P0-0 | DONE | Чистая ветка atomic-turbine/v0.1 на 30aa2bf0 поверх b28ca95e. Launcher из распакованного архива вернул Atomic Turbine 0.1.0. Файл модели Inkling SQ-10 и подготовленный tokenizer доступны. |
| P0-1…6 | В работе | Критерий RC — четыре подтверждённых восстановления через HTTP из чистой распаковки. |

Платформа — macOS arm64, Metal. Обычный запуск использует штатное кеширование Strata. Показатели прошлых спринтов не являются результатами этого RC.

P0-1 DONE. В реальном HTTP smoke Inkling SQ-10 сохранил 1070 токенов (206672056 байт), принял четыре ветки в слотах 0/1 и подтвердил DROP. Qwen IQ3_XXS на одном Metal сохранил 808 токенов через MAIN и подтвердил четыре восстановления и DROP. В обоих случаях ответы на четыре вопроса о launcher верны. В Qwen третий физический слот предназначен родителю.

P0-2 DONE для reference client (444f6167). Путь OpenCode native — DEFER. Проверенная установленная версия 2.0.24, родство сессий доступно в session_v2.parent_id. HTTP hook позволяет привязать заголовок к вызову, но общий токенный префикс зависит от инструментов и системных инструкций конкретного агента. Обычное OpenCode подключение проверяется отдельно.

P0-3. Точечные проверки протокола прошли для конфликтующего создания, проверки владельца и точных токенов, смены поколения, TTL, удаления при активной ветке и повторной попытки DROP после занятого диспетчера. Прошли отдельные существующие кейсы истории инструментов через HTTP, совместимости префикса с tools и отмены во время чтения prompt. Нужная fixture отсутствовала в sparse checkout; восстановлен штатный шаблон, повторно выполнен только этот кейс.
