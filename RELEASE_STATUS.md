## Финальная приёмка архива

`Atomic-Turbine-0.1.0-61d705eb.zip` собран из `61d705eb19b0037605641cc294d0db5e844bc889`. SHA-256 архива — `e9267ea44bff7865e4bac0a4a45148db971b724269a3fc05d6ef24b4f77983da`. Все 678 файлов manifest сверены после распаковки в новый каталог. Изменения пакета после измерений — README, release notes и точное сравнение ответа в demo. Бинарники, launcher и шлюз побайтно совпадают с измеренными. Проверены отдельный обычный запрос и команда `python3 fork_demo.py` с заново подготовленным токенизатором. Все четыре ответа точные, сервер подтвердил 1070 повторно использованных токенов в каждой ветке, два активных слота и один DROP. [Свидетельство финального запуска](atomic/bench/results/package-acceptance.json).

## Границы проверки

Один родитель на процесс, TTL 300 с, два активных слота. Inkling использует FP16 KV и бюджет payload. Qwen использует `--batch 3` с третьим слотом для родителя. Для обеих конфигураций проверен текстовый HTTP API. Широкая матрица моделей, длительная нагрузка, другие платформы и полный suite в эти результаты не входят.

## Измерения

В каждой паре движки запускаются в отдельных свежих процессах на одном Mac. Порядок по парам — stock/fork, fork/stock, stock/fork. Штатное кеширование и batching включены. Время запуска моделей и HTTP-сервера исключено. Память — максимум физического footprint процесса движка по macOS rusage, включая веса. Столбец «три запуска» дан в порядке пар.

### Warm fan-out · Inkling

Время после одинаково подготовленного родителя до окончания всех веток и DROP. Исходный prefill вынесен отдельно. Нативный протокол, два активных слота, FP16 KV, chunk 128, drafter off, штатная защита от зацикливания и лимит 128 токенов на ответ.

| Профиль и режим | Три запуска, с → медиана | Медиана пика движка, GiB | Дополнительно |
|---|---|---:|---|
| inkling-16384 · stock | 41.88, 41.38, 50.61 → **41.88** | 3.64 | Первичный prefill 27.10 с |
| inkling-16384 · fork | 5.50, 5.45, 6.98 → **5.50** | 4.14 | Первичный prefill 26.20 с |
| inkling-32768 · stock | 79.14, 90.47, 80.50 → **80.50** | 4.64 | Первичный prefill 57.60 с |
| inkling-32768 · fork | 15.03, 15.79, 13.66 → **15.03** | 5.64 | Первичный prefill 57.22 с |

На синтетических токенных префиксах при свободной жадной генерации штатный batch и fork расходились по токенам. На 32K различалась и длина некоторых выходов. Это наблюдаемое время выполнения конкретных прогонов. Эти строки исключены из числовых обещаний ускорения при эквивалентном результате. Один блок 16K частично пересёкся со сборкой CPU.

### MoE · Qwen

Нативный протокол. Время от первого prefill до окончания четырёх веток и DROP, лимит 16 выходных токенов на ветку. Flash-Next IQ3_XXS, pack + два GGUF, обычный batch 2, fork batch 3 с двумя пользовательскими слотами, Metal arena 6 decimal GB, expert cache 64, контекст 512.

Короткий профиль использует токены из S02. Длинный профиль задаёт четыре вопроса по общей инструкции о checkpoint API. Все выходные токены совпали в каждой из шести пар Qwen. В первом коротком прогоне fork оказался медленнее штатного batch. Физические чтения диска на RC не измерялись.

### Четыре подзадачи · клиент HTTP

## Воспроизведение

Взять Strata `b28ca95e` и Atomic Turbine из manifest.json. Собрать два Release-бинарника Strata теми же CMake-командами, что в Quick Start продукта, с исходниками Strata. На стороне продукта использовать файлы `bin/strata-inkling` и `bin/strata` из ZIP вместе с их ресурсами. На стороне Strata оставить доступ к штатному дереву Metal-ресурсов. На обоих профилях используется штатный scheduler.

Задать `PACKAGE`, `STOCK_SERVER` (upstream terminal/serve/server.py), `STOCK_INKLING`, `STOCK_QWEN`, `INKLING_MODEL`, `INKLING_TOKENIZER`, а также `QWEN_PACK`, `QWEN_GGUF_1`, `QWEN_GGUF_2` и `QWEN_PROFILE`. Из корня продуктового репозитория в окружении с runtime requirements выполнить последовательно для нового каталога результатов:

```sh
python atomic/bench/native.py inkling atomic/bench/profiles.json "$STOCK_INKLING" "$PACKAGE/bin/strata-inkling" results/native
python atomic/bench/native.py qwen atomic/bench/profiles.json "$STOCK_QWEN" "$PACKAGE/bin/strata" results/native
python atomic/bench/http_runs.py "$STOCK_SERVER" "$STOCK_INKLING" "$PACKAGE" "$INKLING_MODEL" "$INKLING_TOKENIZER" results/http
```
